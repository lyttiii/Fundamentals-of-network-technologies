# SOCKS-прокси

## Описание задания

Необходимо реализовать прокси-сервер, соответствующий стандарту **SOCKS версии 5**.

Программа должна принимать в параметрах только номер порта, на котором прокси-сервер будет ожидать входящие подключения от клиентов.

---

## Основные требования

1. Реализовать прокси-сервер по стандарту **SOCKS5**.

2. В параметрах программы передаётся только порт, на котором прокси будет ждать входящих подключений от клиентов.

3. Из трёх доступных в протоколе команд обязательной является только реализация команды `1`:
