# Лабораторная работа: UDP Multicast

## Описание проекта

В рамках работы реализована программа, использующая технологию **UDP Multicast** для обмена сообщениями между несколькими копиями приложения, запущенными в одной сети.

Программа отправляет сообщения в multicast-группу, принимает сообщения от других копий и формирует список активных участников.

---

## Цель работы

Цель лабораторной работы — изучить принципы multicast-взаимодействия и реализовать приложение, которое позволяет нескольким копиям программы обнаруживать друг друга в сети.

В ходе выполнения работы необходимо было:

- изучить работу UDP-сокетов;
- реализовать отправку multicast-сообщений;
- реализовать приём multicast-сообщений;
- обеспечить поддержку IPv4 и IPv6;
- использовать многопоточность для одновременной отправки и приёма данных;
- реализовать определение активных копий программы.

## Функциональность программы

Программа выполняет следующие действия:

1. Принимает адрес multicast-группы через аргумент командной строки.
2. Определяет тип адреса:
   - IPv4;
   - IPv6.
3. Создаёт UDP-сокеты для отправки и приёма сообщений.
4. Подключается к указанной multicast-группе.
5. Периодически отправляет сообщение в группу.
6. Принимает сообщения от других копий программы.
7. Выводит адреса активных копий приложения.
8. Удаляет неактивные копии из списка, если от них долго не приходят сообщения.
9. Корректно завершает работу при нажатии `Ctrl + C`.
