## Асинхронное сетевое взаимодействие

## Описание задания

Необходимо разработать приложение с использованием методов асинхронного программирования или библиотек реактивного программирования.

Примеры технологий:

- `CompletableFuture` для Java
- `RxJava`
- аналоги для других языков программирования

Приложение должно взаимодействовать с несколькими публично доступными API и иметь любой пользовательский интерфейс, основанный на данных, полученных из этих API.

---

## Требования к работе с API

API должны использоваться следующим образом:

1. Все вызовы должны выполняться с помощью HTTP-библиотеки с асинхронным интерфейсом.

2. Все независимые друг от друга вызовы API должны работать одновременно.

3. Вызовы API, которые зависят от данных, полученных из предыдущих API, должны оформляться в виде асинхронной цепочки вызовов.

4. Все результаты работы должны собираться в общий объект.

5. Поэтапный вывод результатов в процессе работы недопустим.

6. Не допускаются блокировки на ожидании промежуточных результатов в цепочке вызовов.

7. Допустима только блокировка на ожидании конечного результата в случае консольного приложения.

---

## Основная идея реализации

Логика программы должна быть оформлена как две функции, каждая из которых возвращает `CompletableFuture` или аналогичный объект в выбранном языке программирования.

Первая функция выполняет поиск вариантов локаций.

Вторая функция выполняет:

- получение погоды по выбранной локации;
- получение списка интересных мест;
- получение описаний найденных мест;
- сбор всех данных в общий результат.

Обе функции должны работать без блокировок промежуточных результатов.
